# Paper 1 — Stage 3C Robustness

Stage 3C tests whether the Stage 3B sign pattern survives stronger inference.

Main tests:
- standardize all four borrower-country GPR measures;
- TWFE with baseline controls;
- borrower-country clustered standard errors;
- legal clauses estimated separately with LPM;
- leave-one-country-out;
- leave-one-year-out;
- crisis-window exclusions;
- optional small-cluster inference status check.

Expected sign pattern to test, not impose:
- Pricing: positive
- Maturity: negative
- Grace period: negative

Robustness is not equivalent to causal identification.
